# UniProxy 0.3.0

## 更新内容

### 多引擎 sidecar

- 主核保持 Mihomo 1.19.32；Xray-only 节点由本地单进程 Xray 26.10.31 sidecar 承载，每个节点生成独立的 127.0.0.1 SOCKS5 inbound，Mihomo 只编译对应的 `socks5` 出站，不把 Xray 当作第二个公共入口。
- sidecar 节点的真实远端地址与凭据只保存在加密配置和 Xray 临时配置中；公开 API、节点列表、日志与错误输出不返回本地 SOCKS 用户名/密码。
- 一个 Xray 进程承载最多 200 个 sidecar 节点；端口范围默认 30000–30999，保存与应用前做回环 TCP/UDP bind 预检，并拒绝与管理端口、独立监听或已有节点端口冲突。
- sidecar 节点只允许单独出站或位于链首；链中间、链尾在保存和编译时直接报错。
- sidecar 启动失败或崩溃时只影响其节点：进程按有界退避自动重启（最多 3 次），相关节点标记不可用，代理池返回失败/REJECT，不直连回退。

### Xray 节点导入与安装

- 支持识别 Xray-only URI：VLESS Encryption（含 ML-KEM-768 1184 字节 key）、VLESS/VMess XHTTP、Reality spiderX/mldsa65Verify、FinalMask、TLS cipher suites 等；严格解析无法证明等价时仍报错，不静默降级为 Mihomo。
- 固定 Xray 26.10.31 在线安装器：Windows/Linux × amd64/arm64 官方资产名与内置 SHA256，双重摘要校验、多文件 ZIP 平坦白名单安全解压、无覆盖发布；也支持自动发现数据目录、显式路径与 PATH 中的 Xray。
- 固定版本 Xray 已移除 Trojan flow，导入和配置生成阶段均直接拒绝，避免生成必然启动失败的配置。

### 设置与界面

- “运行与设置 → 检测与端口”新增“04 多引擎 Sidecar”：功能开关默认关闭、实际进程状态/版本/启用节点数、端口范围与在线安装面板；安装期间不自动应用配置。
- 节点页新增引擎徽章与 sidecar 实际状态；导入预览显示引擎，Xray-only 节点与仅预览节点分别标注。
- 关闭 sidecar 开关但仍有启用 Xray 节点时显示明确警告；保存/应用失败时保留待应用状态并展示可读错误。

## 兼容范围

- 旧 state 中 `Node.Engine` 为空时自动按 `mihomo` 处理，原有节点、代理池、代理链和监听行为不变；本版不包含 SQLite schema 迁移。
- 本版仍固定 Mihomo v1.19.32；Xray sidecar 为可选组件，默认关闭。已有 v0.2.9 数据目录、主密钥与备份可按原方式沿用。
- 本地 sidecar 只监听回环地址，不作为对外入口；sing-box sidecar 暂缓，等确有 AnyTLS/Snell/ShadowTLS/Naive/Tor 等协议需求时再加入。
- 真实公网节点的可用性、延迟和吞吐取决于节点、网络与内核环境，不作保证。

## 升级与数据安全

1. **先退出旧 UniProxy 实例并确认其内核退出，再替换主程序**。沿用原数据目录、匹配主密钥和启动参数，不必重新导入已有数据。
2. **不要在运行中复制或覆盖数据库**；仅复制在线主库不是一致备份，不得混用不同数据库的 WAL/SHM。物理备份、迁移或恢复前，源与目标实例都须停止。
3. Xray 在线安装完成后不会自动应用配置；需在界面点击“重新应用配置”。安装器不覆盖已有自定义 Xray 路径，也不会替换正在运行的 sidecar。
4. 本版发布不会自动替换正在运行的程序，部署需单独执行。
