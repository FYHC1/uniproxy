# UniProxy 0.2.7

## 更新内容

### 代理链

- 新增独立「代理链」页面：把 2–16 个节点按顺序串接成一条出口链路，入口监听可绑定整条链，不复制、不修改原节点。
- 每条链编译为有序合成出站副本：第一跳正常出站，第二跳起通过 `dialer-proxy` 连接前一跳，入口只绑定末跳；节点的原配置、标签和凭据保持不变。
- 全有或全无：任一跳缺失、禁用、仍有中转错误、重复或跳数越界时，整链不生成，绑定入口编译为 REJECT 并显示具体原因，不缩短链、不回退直连。
- 新增 `GET/POST /api/chains`、`PUT/DELETE /api/chains/{id}`、`POST /api/chains/with-listener`、`POST /api/chains/{id}/test`；监听新增 `chain` 目标类型，链与入口可在同一事务创建，端口支持自动分配。
- 整链延迟通过内核末跳的真实 delay 接口检测，不写节点健康；删除被引用的节点会停用整条链及其入口，并保留 NodeIDs 便于恢复。
- 创建/编辑窗口采用双栏布局：左侧按分组和状态筛选、搜索、按名称或延迟排序并测试可见节点；右侧维护链路顺序，支持上移、下移、移除、入口/出口标记、少于 2 跳提示和清空确认。列表支持搜索、状态筛选、复制为停用副本、启停、编辑与删除。

## 兼容范围

- 无数据库 schema 迁移；旧配置会自动补齐空的代理链列表，节点、分组、代理池、监听和订阅数据保持原样。
- 新增代理链 API 与监听 `kind=chain`；原有节点、代理池、监听和订阅接口保持不变。固定 Mihomo 仍为 v1.19.32，不改变节点协议解析、SSRF/Fake-IP 防护或 TLS/证书校验。
- 代理链入口为 TCP 入口；UDP 入口仍只允许回环，并要求链路每一跳节点都支持 UDP。入口监听复用现有地址、端口、认证和冲突校验。
- 本机回环测试证明转发路径；真实公网远端节点的可用性、延迟和吞吐取决于节点、网络和内核环境，不作保证。

## 升级与数据安全

1. **先退出旧 UniProxy 实例并确认其内核退出，再替换主程序**。沿用原数据目录、匹配主密钥和启动参数，不必重新导入已有数据。
2. **不要在运行中复制或覆盖数据库**；仅复制在线主库不是一致备份，不得混用不同数据库的 WAL/SHM。物理备份、迁移或恢复前，源与目标实例都须停止。
3. 本版无 schema 迁移；已有兼容内核无需重装。发布不会自动替换正在运行的程序，部署需单独执行。
