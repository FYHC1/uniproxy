# UniProxy 0.2.9

## 更新内容

### 协议解析三档

- 严格解析保持与固定 Mihomo 1.19.32 的可证明等价映射：不能证明语义的字段仍会报错，不静默改成 TCP、丢弃 TLS/Reality 校验或伪造支持。
- 新增仅用于预览的宽松解析：可识别但会丢失语义的 URI 参数进入“仅预览”列表并附固定原因，不会写入节点库、SQLite 或运行配置。
- 导入预览区分“可导入”和“仅预览”：可导入节点与严格解析一致；仅预览节点只用于诊断来源，不参与订阅提交。订阅提交仍保持整源 all-or-nothing。

### 严格兼容修复

- 接受并归一化常见导出器写法：`security=false`、`packetEncoding=none`、`type=none`、`extra=null`、空 `fp`、`fp=ios`、WebSocket `headerType=none`、TCP 的 `path`/`host` 占位。
- 支持 1184 字节 VLESS Encryption key；保留原有 XHTTP、HTTPUpgrade、VMess KCP、ECH、vcn/pcs 与 Reality 映射。
- Xray-only 的 Reality/finalmask、unsafe 指纹等字段只进入预览并标记原因，不作为可应用节点。

### 真实订阅验证

- 使用 1064 条真实 VLESS 订阅做本地解析：严格模式 697 条成功；预览模式 697 条严格 + 365 条降级，共 1062 条可展示，剩余 2 条保留错误。
- 解析成功不等于节点可用；真实连通、握手和吞吐仍需单独检测。

## 兼容范围

- 本版只改变节点 URI 的解析与预览，不改变固定 Mihomo v1.19.32、节点转发语义、订阅刷新策略或 SQLite 配置格式。
- 宽松预览是诊断视图，不是受支持的协议能力；预览节点不能导入或应用。
- 真实公网节点的可用性、延迟和吞吐取决于节点、网络与内核环境，不作保证。

## 升级与数据安全

1. **先退出旧 UniProxy 实例并确认其内核退出，再替换主程序**。沿用原数据目录、匹配主密钥和启动参数，不必重新导入已有数据。
2. **不要在运行中复制或覆盖数据库**；仅复制在线主库不是一致备份，不得混用不同数据库的 WAL/SHM。物理备份、迁移或恢复前，源与目标实例都须停止。
3. 本版无 schema 迁移；已有兼容内核无需重装。发布不会自动替换正在运行的程序，部署需单独执行。
