# UniProxy 0.2.8

## 更新内容

### 全局界面视觉刷新

- 统一应用主题、字体、间距、按钮、表单、表格和弹窗样式，改善层级与可读性，避免重复的二级标签和冗长说明，让布局本身表达结构。
- 优化桌面与移动端导航、登录页错误提示、空状态和状态标签；页面在窄屏下保持可操作，不出现横向溢出。

### 代理池编辑体验

- 编辑窗口把入口监听区上移，分组区固定为约四行高度并可独立滚动，节点区加宽加高，批量操作栏常驻，减少上下往返。
- 节点选择改为即时勾选，保留搜索、状态筛选、排序和真实延迟检测；批量加入、移除和清空确认在底部直接完成。

### 代理池卡片紧凑化

- 出口节点区改为双列网格，容器宽度不足 430px 时自动切换单列；列表固定高度内滚动，每页最多显示 10 个节点。
- 节点卡压缩为两层：首行显示健康状态、名称、延迟和测速/移除操作，次行只保留协议标签和该节点自身的异常状态；地址、中转、最近检测和错误信息收进展开详情。
- 缩小卡片内边距和节点间距，桌面双池、单池宽屏与移动端都提高了首屏节点数量；触控设备操作按钮保持 44×44。

### 新建代理链弹窗

- 调整创建/编辑窗口的监听区、节点筛选区、已选链路和凭据区域顺序，支持端口自动或手动分配、分组与状态筛选、名称/延迟排序、真实延迟检测和入口/出口标记。

## 兼容范围

- 本版只涉及前端界面与交互布局，没有 API、数据模型、配置 schema 或 Mihomo 内核变更；节点、分组、代理池、代理链、监听和订阅数据保持原样。
- 固定 Mihomo 仍为 v1.19.32，不改变节点协议解析、SSRF/Fake-IP 防护或 TLS/证书校验。
- 浏览器验证覆盖桌面和窄屏布局；真实公网节点的可用性、延迟和吞吐取决于节点、网络和内核环境，不作保证。

## 升级与数据安全

1. **先退出旧 UniProxy 实例并确认其内核退出，再替换主程序**。沿用原数据目录、匹配主密钥和启动参数，不必重新导入已有数据。
2. **不要在运行中复制或覆盖数据库**；仅复制在线主库不是一致备份，不得混用不同数据库的 WAL/SHM。物理备份、迁移或恢复前，源与目标实例都须停止。
3. 本版无 schema 迁移；已有兼容内核无需重装。发布不会自动替换正在运行的程序，部署需单独执行。
