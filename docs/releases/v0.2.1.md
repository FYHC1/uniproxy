# UniProxy 0.2.1

## 更新内容

- **内置 Mihomo 在线安装**：启动时自动检测已有内核；缺失时在管理面板提示安装，无需另外下载或运行独立安装器。
- **运行与设置页安装入口**：可随时在线安装、查看进度及重新检测手动放置的内核。下载在后台执行，关闭弹窗或切换页面不会中断；失败显示原因并支持重试。
- **安装与运行分离**：安装完成并通过版本检测后，需点击“重新应用配置”启动代理；安装本身不改变配置版本、不自动开启监听。
- **安全保护**：固定 Mihomo v1.19.32，校验官方来源、HTTPS、重定向和双重 SHA256 摘要；不执行远程脚本，不覆盖已有文件，不替换运行中的内核，并防止重复安装请求。
- **重新检测恢复**：已下载文件的首次版本检测超时时保留文件，可重检而不必重复下载。手工修复内核后不再显示过期安装失败。
- **简化分发**：发布资产仅提供 UniProxy 主程序与校验和，不再附带 core-install；Docker 构建也不再预下载内核，而是在首次运行时由 WebUI 安装到 /data/core 持久卷。

## 下载选择

| 平台 | 文件 |
|---|---|
| Windows x64 / Intel / AMD | `uniproxy-windows-amd64.exe` |
| Windows ARM64 | `uniproxy-windows-arm64.exe` |
| Linux x64 / Intel / AMD | `uniproxy-linux-amd64` |
| Linux ARM64 | `uniproxy-linux-arm64` |

请使用同一 Release 的 `SHA256SUMS.txt` 校验下载文件。Linux 下载后需为主程序添加执行权限。

## 升级与首次运行

1. 备份并正常停止旧 UniProxy，再替换主程序；沿用原数据目录及匹配主密钥，不需要重新导入数据。在线 SQLite 备份不能只复制主数据库文件。
2. 启动新程序并刷新浏览器。若已有兼容 Mihomo，会自动检测，无需重装；若缺失，按弹窗在线安装，完成后应用配置。
3. 下载由 UniProxy 所在主机访问官方发布服务，不使用浏览器或系统 HTTP 代理。无法访问时可手动放置固定版本内核并重新检测。
4. 安装目标目录需可写并支持硬链接（例如 NTFS、ext4）。已有不兼容或损坏文件需管理员手动确认处理，不会自动覆盖。

## 验证与边界

- 功能验收包括 Go 全量及真实本机 Mihomo 回归、36 项前端工具测试、34 项隔离真实 API 浏览器测试、离线 UI 状态/会话回归，以及临时目录的真实官方下载安装与显式启停验证。
- 发布构建覆盖 Windows/Linux × amd64/arm64；交叉编译不等于全部平台实机验收。Linux、Windows ARM64 和 Docker 的实际部署仍需目标环境验证。
- 本版本没有升级 Mihomo、改变系统代理/防火墙或放宽仅回环 UDP 等安全边界。发布操作不自动升级任何正在使用的实例。
