# UniProxy implementation contract

Updated 2026-10-20. This is the current source/API contract, not an active delegation prompt. Read [documentation index](<README.md>) and [session handoff](<session-handoff.md>) for status; previous child ownership is archived in [coordination](<coordination.md>).

## Architecture and scope
Go 1.24+ backend module github.com/uniproxy/uniproxy, React+TS frontend, SQLite persistence, independent Mihomo core. Main goal: real working management and TCP/UDP proxying, no fake metrics/nodes. .js imports optional frontend. The canonical model is [internal/model/types.go](<../internal/model/types.go>), with public TypeScript projection in [src/shared/types.ts](<../src/shared/types.ts>). Keep model/API/UI types and regression tests aligned. Previous parallel implementation is complete; new work must assign explicit disjoint scopes rather than inherit old child ownership. Do not silently change dependencies or format another active writer’s files.

## API contract
All same-origin /api responses JSON. Error {error:string,code?:string, runtime?:RuntimeStatus}. Bootstrap: State public projection plus runtime:RuntimeStatus, coreInstallation:CoreInstallation, activities:Activity[], jobs:Job[]. Collections always arrays. Node.config/fingerprint/dialerIdentity/manualGroupIds/sourceGroups omitted. Public nodes may expose dialerId/dialerName/dialerError; these identify routing dependencies, not credentials. Listener users has username/hasPassword only (password omitted). Subscription URL redacted query+credentials in list; editable names/group/interval only (new URL via new source). Updated mutation response is {data: ENTITY_OR_RESULT, runtime:RuntimeStatus}; if core absent/apply fails, save desired configuration but runtime.dirty true with a descriptive nonempty lastError; do not claim the saved revision is running. Successful apply clears lastError. UI must show warning. Core validation failure when available rejects mutation (400); unexpected apply failure saved as pending with status warning and old live config retained or recovered. Auto apply each configuration mutation, batch one apply. Health metadata does not change config revision. /api/health public {ok:true,version:<build version>}; the version is injected at build time from internal/version (release builds use -ldflags), so a running process can be matched to its release instead of reporting one hard-coded string. The current source default version is 0.2.1 with Commit=dev/Date=unknown, so unstamped builds omit commit/date; explicitly stamp unreleased artifacts to distinguish them from release assets. Release tags inject the exact version, commit and UTC build date.

## Display names

Group, node, pool, listener and subscription names are 1–160 runes and must not contain control characters. The ceiling applies to the stored display name only: an imported upstream label longer than that is shortened on a rune boundary with a trailing "…" instead of dropping the node, so preview shows exactly what will be saved. A label longer than 1024 runes or containing control characters stays invalid input. Labels are presentation only; identity is the fingerprint. Names derived by the server (for example a batch dedicated listener from its node name) reserve room for their suffix instead of producing a value the limit rejects. Validation errors name the field that is actually wrong.

## Current validation bounds

Listener host must be literal IP, port1024..65535 excluding admin; credential max255bytes, username no colon/control. SOCKS/mixed native UDP is loopback-only because pinned core UDP does not authenticate packets; UDP with in-user pool forbidden. Pool interval10..86400sec, timeout500..30000ms, tolerance0..10000ms. Subscription interval5..10080minutes. Settings timeout500..30000ms, concurrency1..32, download1024..104857600bytes, health interval30..86400sec, port range1024..65535. Snapshot max32MiB; backup request max40MiB; regular JSON request max12MiB, imports5MiB. A manual Stop suspends automatic apply until explicit runtime Apply; restart resumes desired config. Tasks require appliedRevision==desiredRevision and discard results across configuration generation changes.

Normalized Protocol values: vless,vmess,trojan,ss,hysteria,hysteria2,tuic,ssh,socks5,http (Mihomo naming). ParsedNode.Config is native Mihomo outbound map (without user-controlled name); password/uuid/etc retained here ONLY. Node.UDP true only compatible config. Invalid/unsupported options should error, not silently downgrade security. Detect unsafe paths (private keys/cert paths etc), detour, scripts, urltest pseudo-outbound. Clash document dialer-proxy is supported ONLY via a validated same-document concrete-node graph: raw config keys still forbidden; ParsedNode.DialerProxy/DialerFingerprint resolve into stored Node.DialerID and compiler-injected stable n-ID names. See docs/relay-change-contract.md. yaml.v3 available. All protocol aliases standard, TLS/Reality/ws/grpc support. Limits5MiB 5000nodes depth bounded. ## State and refresh
Groups many-to-many. Node manualGroupIds plus sourceGroups[sourceId] groupIds -> union groupIds. Fingerprint excludes node label; stable credential/config identity. SourceIDs track multiple subscriptions; Manual retains manually imported same node. On complete successful refresh reconcile one source only; remove vanished refs; delete orphan non-manual nodes; remove pool static node refs; disable but keep stale dedicated listener config. Bad/partial/empty or >50% deletion refresh protected unless explicit force for empty/shrink (never force invalid parse). Preserve node manual names/enabled/manual groups. Unknown health not equal unhealthy. Only the SQLite state payload is AES-GCM encrypted with a separate local key; activity/schema are not whole-file encrypted. Backups/exports are explicitly plaintext and sensitive; copying a live WAL database requires a consistent backup method. Node.DialerIdentity retains upstream identity after deletion, is preserved in backups, and is removed only in public response copies. Restore sanitizes raw native maps and recalculates fingerprints using the stable graph.
